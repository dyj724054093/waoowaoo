# moyin优点迁移落地清单（面向waoowaoo，2026-03-06）

## 1. 目标

本清单不做代码改动，只定义可执行迁移路径。
目标是把对方项目中高收益、低风险的能力迁移到 waoowaoo。

---

## 2. 迁移优先级总览

P0（马上吸收）
- 多Persona分工链路（按阶段拆职责）。
- 三层提示词体系（首帧、动态、尾帧）。
- needsEndFrame 条件化规则。
- 视频提示词分层拼装（Camera、Lighting、Subject、Mood）。

P1（有条件吸收）
- 角色6层身份锚点（identityAnchors）+ negativePrompt。
- 场景固定约束（主场景不可漂移）与闪回处理规则。
- Provider 参数治理（分辨率、比例、时长、固定机位）。

P2（谨慎吸收）
- 多端点路由和复杂轮换。
- 预告片自动选片。
- 全量超长 Prompt 的一体化大模型调用。

---

## 3. P0清单（建议第一阶段就做）

3.1 多Persona分工链路
- 学习价值：把一个大Prompt拆成多个小任务，稳定性显著提升。
- 风险：调用次数上升。
- 最小落地策略：先拆 5 个节点。
  1) 叙事骨架节点。
  2) 视觉描述节点。
  3) 摄影参数节点。
  4) 首帧节点。
  5) 动态与尾帧节点。

3.2 三层提示词体系
- 学习价值：从单一视频提示词升级为首帧+动态+尾帧，能显著减少动作失真。
- 风险：字段变多，需要明确回填逻辑。
- 最小落地策略：先定义统一输出契约。
  - imagePrompt（首帧）。
  - videoPrompt（动态）。
  - endFramePrompt（尾帧，可空）。

3.3 needsEndFrame 条件化
- 学习价值：避免所有镜头都强制尾帧，减少不必要成本。
- 风险：判断规则不清会误判。
- 最小落地策略：先用规则判断，不依赖模型自由发挥。
  - 有位移、镜头运动、道具状态变化时，设 true。
  - 纯对白静态镜头可设 false。
  - 不确定时优先 true。

3.4 分层拼装视频提示词
- 学习价值：可解释、可调试、可回放。
- 风险：层与层之间重复描述。
- 最小落地策略：先固定层顺序，再做去重。
  - Camera: 景别、机位、运动、焦段、景深。
  - Lighting: 光型、方向、色温。
  - Subject: 人物调度、动作摘要、视觉焦点。
  - Mood: 情绪、叙事功能、镜头意图。

## 4. P1清单（第二阶段）

4.1 角色6层身份锚点
- 学习价值：角色跨镜头一致性显著提升。
- 风险：字段复杂，解析失败率可能上升。
- 最小落地策略：先上 3 层，再扩到 6 层。
  - 先上：五官、独特标记、发型。
  - 后上：骨相、颜色锚点、皮肤纹理。

4.2 场景固定约束与闪回规则
- 学习价值：能明显减少场景漂移。
- 风险：过强约束会降低创作自由度。
- 最小落地策略：明确主场景字段不可改；闪回只允许画面叠加表达。

4.3 Provider 参数治理
- 学习价值：提示词与平台参数一体化，减少生成端不确定性。
- 风险：不同平台参数格式不一致。
- 最小落地策略：先抽象统一参数层，再做平台映射。

---

## 5. P2清单（第三阶段）

5.1 多端点路由与复杂轮换
- 学习价值：提升容灾与吞吐。
- 风险：排障复杂度大。
- 建议：等 P0/P1 稳定后再引入。

5.2 预告片自动选片
- 学习价值：提升内容再利用能力。
- 风险：依赖上游镜头标注质量。
- 建议：先做人工辅助选片，再逐步自动化。

5.3 超长一体化Prompt链路
- 学习价值：一次产出全字段，功能完整。
- 风险：token 压力大、解析风险高。
- 建议：保持多节点协同，避免回退到超长单节点。

## 6. waoo可直接采用的验收指标

第一组：角色稳定性
- 同角色跨10镜头身份一致率。
- 同角色服装与发型连续一致率。

第二组：场景稳定性
- 主场景漂移率。
- 闪回镜头误改主场景比例。

第三组：动态质量
- 动态提示词动作动词密度。
- 尾帧启用镜头的运动闭合率。

第四组：工程可控性
- 单镜头可追溯字段完整率。
- 重跑3次结果方差。
