# moyin Persona量化评分表（2026-03-06）

## 1. 评分模型

评分维度（每项满分10）：
- 效果贡献：对最终画面/视频质量的直接贡献。
- 可迁移性：迁移到waoowaoo的难度和适配性。
- 工程可控性：输出契约清晰、可追溯、可调试程度。
- 成本效率：调用成本与收益比。
- 风险可控性：失败后是否容易兜底。

综合分（百分制）计算：
- 综合分 = 效果贡献30% + 可迁移性20% + 工程可控性20% + 成本效率15% + 风险可控性15%

说明：
- 分数用于优先级决策，不是绝对结论。
